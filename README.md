# V9 Lite (distribuição)

Instalação no Mac, com dois cliques: baixe o [Instalar-V9Lite-Mac.zip](https://github.com/Hardyrx/v9lite-dist/raw/main/Instalar-V9Lite-Mac.zip),
abra o zip e dê dois cliques em "Instalar V9 Lite.command" (na 1ª vez: botão direito > Abrir).

Ou, se preferir, cole no Terminal:

    curl -fsSL https://raw.githubusercontent.com/Hardyrx/v9lite-dist/main/instalar_mac.sh | bash

O pacote é cifrado: só abre em computador liberado pelo suporte do V9 (código da máquina).
